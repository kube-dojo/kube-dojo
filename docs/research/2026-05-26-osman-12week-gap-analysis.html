Osman 12-week LLM-engineering roadmap — coverage matrix (2026-05-26)

Context

Following KubeDojo issue #1535 and the predecessor analysis of chapters 1-3 (2026-05-21), we audited KubeDojo's AI/ML engineering curriculum against Ahmad Osman's chapter 5 roadmap. Osman's roadmap details a 12-week "build → plot → break → explain → ship" practitioner journey, encompassing ~30 distinct topics ranging from tokenization and positioning to serving optimizations and mechanistic interpretability.

While KubeDojo does not map 1:1 to external social-media content, Osman's sequencing serves as an excellent stress-test for KubeDojo's internal Information Architecture (IA). The goal of this analysis is to identify both topic gaps (where technical concepts are missing) and sequencing gaps (where topics exist but are scattered and inaccessible as a unified practitioner journey).

Sequencing gaps

While the topic coverage is statistically excellent (24 Covered, 3 Partial, 3 Missing), a profound sequencing gap exists. Osman's true pedagogical value is the integrated, step-by-step nature of building an LLM skillset. Currently, a KubeDojo learner must manually bounce across five separate tracks (generative-ai, deep-learning, ai-infrastructure, advanced-genai, and ai/open-models-local-inference) to absorb this stack. There is no central narrative that weaves these isolated primitives into a cohesive engineering system.

Recommended net-new modules (3)

  1. Module 1.13 — Advanced Inference: Speculative Decoding and Medusa Heads
    Placement: ai-ml-engineering/ai-infrastructure/
    Scope: Draft models vs target models, acceptance criteria, Medusa multi-head draft generation, and hands-on tuning of a speculative loop in vLLM.
    Prerequisite chain: module-1.3-vllm-sglang-inference.md
  2. Module 1.11 — Mixture of Experts (MoE) Architectures
    Placement: ai-ml-engineering/deep-learning/
    Scope: Deep dive into MoE architectures: Routers, expert selection algorithms (Top-K, Sinkhorn), capacity factors, load balancing loss functions, and tradeoffs of sparse vs dense scaling.
    Prerequisite chain: module-1.10-modern-transformers-rope-and-attention.md
  3. Module 1.13 — Mechanistic Interpretability: SAEs and Circuits
    Placement: ai-ml-engineering/advanced-genai/
    Scope: Fundamentals of dictionary learning, identifying monosemantic features using Sparse Autoencoders (SAEs), mapping attention circuits (e.g., induction heads), and editing model representations.
    Prerequisite chain: module-1.10-modern-transformers-rope-and-attention.md

Recommendation: explicit project-ladder sub-track?

YES. We strongly recommend building ai-ml-engineering/synthesis-apps/the-12-week-llm-stack/ as a capstone project ladder. Instead of rewriting the theory taught in the core modules, this sub-track should serve as a practical, week-by-week shipping guide that links directly back to the scattered theory files. This preserves KubeDojo's robust academic taxonomy while providing the highly sought-after, linear "builder's journey" that makes roadmaps like Osman's so popular.
