## Recommendation

- 7 models confirmed 1M-class in current corpus: `claude-opus-4-7`, `claude-sonnet-4-6`, `gemini-3.1-pro-preview`, `gemini-3.5-flash-high`, `gemini-3.1-flash-lite-preview`, `grok-4.3`, `qwen3.6-plus`.
- 3 models worth adding or wave-testing: `claude-sonnet-4-6-thinking` if the route exposes thinking distinctly, `qwen3.6-flash` as a cheaper Qwen 1M sibling, and `qwen3-coder-plus` for code-heavy orchestration lanes.
- Models to drop or flag: do not add `claude-opus-4-7-thinking`, `gemini-3.5-pro-preview`, or `grok-4-fast-reasoning` until provider docs expose them as distinct available routes with explicit context/pricing. Keep `grok-4.3` flagged for unresolved >200K pricing.
- Cost note on Sonnet 1M: current Anthropic pricing docs say Sonnet 4.6 has full 1M at standard pricing with no long-context premium, so the previous "2x above 200K" assumption should be retired for Claude Platform API billing.
- Cost cliffs to model in calibration economics: Gemini 3.1 Pro Preview input doubles above 200K prompt tokens; xAI Grok 4.3 says >200K pricing changes but did not reveal the alternate rate in the fetched static docs.
- Source coverage: 16 source pages used; no 404s or access blockers. The only blocker was incomplete disclosure of xAI's higher-context price table in the static docs payload.
