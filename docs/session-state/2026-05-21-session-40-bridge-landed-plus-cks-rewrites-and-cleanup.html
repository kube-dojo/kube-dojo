5. Dispatch frustrations — three to memorize

5.1 Agy long-prompt hang (new failure shape)

Smoke test (ab ask-agy "Reply 'OK'") worked: 6s elapsed / 2-char response. But the ~1000-char CKS review prompt sat at 0 bytes for 30+ minutes with no output. Distinct from the two failure shapes in feedback_agy_rate_limit_detection.md — neither quota-exhaust (3s/0/null) nor OAuth-expiry (32s with auth-prompt body). New memory feedback_agy_bridge_long_prompt_hang.md documents this third shape and the rule: abandon after 5 min; sonnet R1 alone is sufficient when verdict is explicit.

5.2 PR body Learner check needs verbatim quote

The content-merge hook (block-content-merge-without-learner-check.sh → _lib_pr_check.py:check_learner_quote) uses strict quote in contents substring match. PR #1398 body had quote "...rule for a request." (with period) but the module sentence continues "...rule for a request, so place narrow..." (comma, no period). 5+ minutes lost to retrying the merge before tracing the punctuation drift via direct Python invocation of the hook helper. New memory feedback_pr_body_learner_check_verbatim.md captures the rule + related &&-chain pitfall.

5.3 gh pr edit + gh pr merge chained with &&

Even after fixing the quote, chaining gh pr edit --body-file foo && gh pr merge --squash failed: the merge half fires the hook before the edit propagates to gh's view of the PR. The edits succeed individually but the merge in the same Bash invocation sees the old body. Split into separate Bash calls; the second invocation succeeds.
