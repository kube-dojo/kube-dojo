Dominant calque class this batch: active present participles (-ючий/-учий)

The recurring real defect across all three pages was the active present participle — оточуючий, зростаючий, працюючий, існуючий, розчаровуючий — a codified non-normative form in standard Ukrainian (a calque of Russian -ающий/-ующий). Fix = relative clause / adjective / nominalization (навколишній, наявний, робочий, дедалі більший, прикрий). This is bedrock Український правопис grammar, not a corpus-lookup matter — high-confidence, fixed on sight. The secondary class was наступн- used as a pointing-word for content reproduced immediately below ("type the following…" → такі/наведене нижче, the следующі-calque); EN-source-grounded before editing.

Verified-and-left (don't over-edit good prose): all являється grep hits were substrings of з'являється (correct UA — the documented #1922 gate FP); all sequential наступн- uses ("the next command/reader/module"); при копіюванні/при видаленні (borderline, acceptable modern usage). The s139 translations remain strong — the full read mostly certifies and surfaces a small number of genuine reframes per page.
