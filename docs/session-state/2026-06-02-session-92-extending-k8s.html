Lessons / catches worth carrying forward

Code-heavy tracks: the defects live where the verifier is blind. Every P1 this session was a code/API-correctness bug (a goroutine deadlock, a CreateOrUpdate immutable-field wipe, a non-compiling field reference, stale scheduler-plugin signatures) — all on modules the verifier passed at T0. Cross-family review (especially opus pulling upstream source) is the only gate that catches these. Brief code-heavy reviews toward compile-conceptually / build-against-the-pinned-version, not just prose/density.

Ground-checking corrected two reviewer misdiagnoses — both would have introduced errors. (1) deepseek flagged 1.5's env.ValueFrom as a *corev1.EnvVarSource mismatch; the real type was the module's custom EnvVar{Name,Value} with no ValueFrom field at all — its proposed ConfigMapKeyRef fix wouldn't have compiled either. (2) opus suggested moving 1.7's imports to k8s.io/kube-scheduler/framework; the canonical interface.go still lives at k8s.io/kubernetes/pkg/scheduler/framework (the module's existing import), so I kept that path and applied only the web-verified signature changes. Reinforces feedback_three_quality_axes and the ground-check-deepseek rule.

Scheduler-framework signatures churn across minor versions. Score dropped nodeName string for nodeInfo NodeInfo; CycleState/NodeInfo are interfaces (no pointer); EventsToRegister gained ctx+error in 1.32; PreFilter gained nodes []NodeInfo. Web-verified against the v1.35 interface. Added a one-line "confirm against your cluster's godoc" hedge so the module stays honest as the API keeps moving. Same applies to any future scheduler/extending content.

Version facts web-verified this session: ValidatingAdmissionPolicy GA 1.30; MutatingAdmissionPolicy beta 1.34 → GA 1.36 (so beta on the 1.35 standard); CEL x-kubernetes-validations GA 1.29; Operator Framework = CNCF Incubating; kubebuilder = kubernetes-sigs (not CNCF).
