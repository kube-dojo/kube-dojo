Operational lessons (new this session)

1. The codex review surfaces the real composer-2.5 slip class

Out of 7 cursor-authored PRs reviewed by codex this session: 4 came back NEEDS_CHANGES (#1506, #1511, #1510, #1513) and 3 came back PASS/APPROVE (#1512, #1508, #1509). The NEEDS_CHANGES findings included:

  • Fabricated CLI commands documented in a runbook whose whole purpose was to STOP this exact class (#1513 finding 1: ab ask-gemini --review --allow-write doesn't parse).
  • Silent false-bless paths in verifier docs (#1513 finding 2).
  • P1 race conditions in concurrent UI helpers (#1507).
  • Broken regex / unmaintained fallback paths (#1506 HIGH — handoff-path parser).
  • Third-party CDN dependencies in artifacts (#1510 P1 — Mermaid).
  • Test coverage that doesn't exercise critical branches (#1511 finding 2 — repo-mismatch not tested).

This validates the symmetric cross-family routing rule. Composer-2.5 ships fast but slips on these classes; codex catches them. Inverse is also true (composer-2.5 caught real bash runnability bugs in codex-authored PRs in session 50).

2. Background-task watcher pattern

Don't use for ... done & to spawn watchers — parent shell exits → orphan children, no notifications. Do use individual run_in_background: true per task. Cost: more tool calls; benefit: real notifications.

3. Auto-merge fails silently when --delete-branch can't delete locally

gh pr merge N --squash --delete-branch --auto fails the WHOLE command when the local branch is still checked out in a worktree. Workaround: drop --delete-branch, let server-side --delete-branch happen via PR-merge settings, clean up the local branch + worktree manually after merge.
