Pattern observations worth memorializing:

  • Cost per rewrite: ~$0.10-0.20 in subscription dispatches (codex gpt-5.5 architect + 2 reviews + 1 fixup). Wall-clock ~30-45 min including CI + merge. Extrapolated to 160 modules: ~$16-32 budget, ~80-120 hours wall-clock (3-4 modules per parallel session). Affordable.
  • Dual-reviewer discipline pays: sonnet + agy together caught complementary findings each time. Sonnet specialized in pedagogy/exam-context judgment (PR #1363 B1+B2 blockers — without sonnet we'd have shipped a CKS module without the kube-apiserver wiring step that the exam tests directly). Agy specialized in factual sharpness (PR #1362 wildcard usernames, malformed YAML; PR #1363 KMS v1 status correction). Either alone would have missed real issues.
  • Verifier T0/T1 gate is non-negotiable: both pilots required the codex writer to verify T0 before push. The session-32-built deterministic verifier (median_wpp ≥ 28, mean_wpp ≥ 30, short-para-rate ≤ 20%, body_words ≥ 5000, sources ≥ 10) holds the quality floor. Without it, codex tends toward shorter "list of facts" output that fails pedagogically.
  • Codex gpt-5.5 architect class + --search is the right writer tier: spark tier (gpt-5.3-codex-spark) is sufficient for surgical edits and fixups, but full rewrites need gpt-5.5's depth + tool access. Confirmed across T2-13 + both CKS rewrites.

Calibration framework — designed, build queued

User asked for a systematic framework to test models × efforts × activities. Launched a multi-agent deliberation (scripts/ab discuss calibration-framework --with codex,gemini --max-rounds 2) which converged on the following architecture.

v1 spec (locked)
DimensionValue
Models4 anchors + 1 rotating challenger slot. v1 anchors: claude-sonnet-4-6 · codex gpt-5.5 · gpt-5.3-codex-spark · agy/Gemini 3.5 Flash (High). v1 challenger: deepseek-v4-pro (high-signal: 5/5 calibration in session 30, BUT caused 2 T0→T3 production regressions in session 33 — directly tests whether the framework catches the calibration-vs-production gap).
Lanes5: code review · content review · fact-check/hallucination · long content writing · architecting
Cells25 (5 lanes × 5 models). Single prompt per cell for v1 smoke; n≥3 prompts per lane comes in v2.
Atomic row keymodel@effort — same model at low/medium/high/xhigh effort is a different row. Avoids hidden averaging.
Canonical storageJSONL + SQLite ledger (codex's architectural correction to the user's "save as MD" mandate). MD/HTML are generated reports. Reuses dispatch_smart.py's existing JSONL + response_path infrastructure.
ScoringDeterministic gates first (build pass, verifier T0, ground-truth count, URL HEAD). LLM-as-judge only for prose with 2 cross-judges. Avoid same-family correlated errors.
Production joinTyped event ledger: approved-stayed-T0 / approved-later-T3 / real-bug-caught / hallucinated-blocker / silent-miss / verifier-failure. NOT a single multiplier (gemini's first-pass 1/(1+patch_turns) rejected as too lossy).
Long-term shapeStatic matrix is just a report. Shadow production routing is the real framework: challenger models review real PRs with NO merge authority until they accumulate evidence. Plan: build for both code-review AND content-review lanes from v1.
Domain scopeSchema multi-domain from day 1 (domain, lane, fixture_id, as_of_date, ground_truth, verifier, production_join_key fields). v1 fixtures KubeDojo-only. learn-ukrainian forks the harness once stable.
CadenceQuarterly full sweep · on-demand single-model add when new model lands · persistent record for regression detection.
Cost25 cells × ~$0.05 = ~$1.25 + 30-60 min wall-clock (parallelizable — 5 providers have independent rate limits).
