The agreed workflow (what actually changes vs s190's ~11-dispatch review)

  1. Deterministic gates first, carrying more: add an rg/grep exercise-consistency gate (the s190 pedagogical grep-bug becomes a free gate, not a reviewer job) + a mechanical risky-EN-term anchor-list extractor.
  2. Two cross-family reviewers, one parallel round — orthogonal axes: codex/gpt-5.5 = fidelity floor (tables, exercises, lab commands, parity) on every module; agy/gemini-3.1-pro = linguistic (naturalness, russicisms, idioms, false-friends) when linguistic risk is real; deepseek = high-risk spotter only. (My R1 argued for one reviewer; codex's orthogonal-axis argument changed my mind — MCP settles "is викатка a lemma" but not "does this read as translationese.")
  3. Structured output kills the R1-miss→R2-find loop: reviewers return a coverage table (EN | UK | verdict | source | class) pre-seeded with the anchor rows — can't skip the table cell — + P1/P2 findings; explicit "table cells/quiz/exercises are first-class prose; one defect → scan ALL siblings."
  4. MCP-ground the reviewers (#2086) so they self-verify before flagging; orchestrator MCP-adjudication is the bridge.
  5. Front-load the author brief with the s190 substitution table + rg-rule (a prevented defect costs zero dispatches; flywheel: promote each wave's generalizable findings).

Budget: ~2–3 dispatches/module (gates → 2 parallel reviews → 1 adjudication → ≤1 class-A fix), down from s190's ~11.

Why agy keeps breaking — and the fix verification saga

Root cause: harness, not model. The Gemini brain is a strong linguistic reviewer; the Antigravity CLI headless path + our adapter is what fails — intermittent no-write/hang/timeout (#2099), fabricated success reports, review hallucinations (ungrounded → invents findings like відповідєю), and (older) containment. The Google seat has been the perennial weak link (gemini-cli was retired for the same class).
