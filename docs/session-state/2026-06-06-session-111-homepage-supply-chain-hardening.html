Security: Miasma worm (June 2026) — what it is + what we shipped

Threat: a credential-stealing npm worm that spread from a compromised GitHub Actions OIDC publishing pipeline (@redhat-cloud-services), runs an obfuscated dropper via a malicious preinstall/install/postinstall hook on npm install, steals creds, and republishes the maintainer's packages with forged provenance. A variant injects backdoors into AI-coding-agent configs. Hit 73 Microsoft repos.

Triage (NOT compromised): 0 refs to the compromised scope; no install hooks in our own package.json; clean git, no injected agent configs; deploy.yml already job-separates the OIDC token from npm ci (build job contents: read, deploy job id-token: write runs no npm); dependabot cooldown + zizmor already present.

#1813 Phase-1 (Prevent + Detect), live on main:

  • Prevent — .npmrc ignore-scripts=true blocks the hook from executing. The two deps that legitimately need native scripts (esbuild, sharp) are rebuilt explicitly: deploy.yml runs npm rebuild esbuild sharp --ignore-scripts=false (plain npm rebuild honours ignore-scripts → would be a no-op).
  • Detect — scripts/security/check_install_scripts.py scans package-lock.json hasInstallScript (authoritative; catches binding.gyp implicit hooks + OS-gated fsevents), uses the lockfile path as identity (kills name-spoof, nested-path, null-name), verifies allow-listed packages' declared hooks ⊆ expected (allow-list abuse), flags npm-alias masquerade + local/file: deps + non-registry sources. Wired into .github/workflows/supply-chain.yml (runs the tripwire + npm audit signatures hard gate on every PR/push). Allow-list: esbuild, fsevents, sharp.
  • Documented residual: a same-name rogue hook on an uninstalled OS-gated allow-listed dep (fsevents on Linux) is caught only by lockfile-integrity diff review — and prevention blocks its execution regardless.

Cross-family review converged after 3 rounds — every demonstrated bypass closed: R1 (codex+deepseek+agy all NEEDS CHANGES: rebuild no-op, binding.gyp miss, name-spoof, OS-gated miss, soft signature gate) → R2 codex (nested-path bypass, demonstrated) → R3 codex (alias-masquerade + local-link, demonstrated). Key reframe: prevention is the primary control; the tripwire is secondary "would-we-notice" — a static lockfile scanner can be gamed at the margins forever, so we fixed every demonstrated bypass and converged rather than chase an infinite R4.
