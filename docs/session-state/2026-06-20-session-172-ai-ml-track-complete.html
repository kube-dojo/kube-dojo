Method & findings

  • Triaged by verify_module.py tier + gate JSON, not density.py (per the s168 5×-undercount lesson) — pinned the EXACT failing gates per module before editing, so each fix brief was literal-complete.
  • The verifier wants the EXACT singular ## Next Module heading (_next_module_link matches ^Next Module$; positions["next"] too). 121/124 modules use singular — only these 2 stragglers were plural → both fail next_module_link AND section_order_correct. One-word rename fixes both gates.

  • Sourcing done inline + web-verified by the orchestrator (curl 200 + canonical-relevance) — the fabrication-prone part, so not delegated. codex independently spot-checked all 15 new source descriptions against primary pages → all accurate/relevant, no findings.
