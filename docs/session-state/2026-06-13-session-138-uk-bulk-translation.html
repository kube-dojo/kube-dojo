⚠ Three hard-won execution lessons (read before resuming the bulk)

  1. agy is SEQUENTIAL-ONLY. Concurrent agy CLI sessions share one ~/.gemini/antigravity-cli/ session state and collide. Run ONE uk_bulk.sh driver at a time (each translates its modules sequentially; each module is ~6 chunked agy calls, ~6 min).
  2. You CANNOT see background-task processes via ps/pgrep from the Bash tool — the sandbox has a separate process namespace (returns empty even when tasks are alive). And piping a driver to tail buffers all output until the pipe closes (looks like 0 bytes mid-run). Verify background progress via the task OUTPUT FILE (run the driver WITHOUT a tail pipe so it streams per-module) + files appearing in the worktree + the completion notification. This session I misread an empty ps as "both streams died" and TaskStop'd two healthy parallel batches — wasted work + a scare. (Also reaffirmed agy-sequential after.)
  3. The bulk worktree was created DETACHED (git worktree add .worktrees/uk-bulk origin/main → detached HEAD). Commits there are GC-bait. git switch -c <branch> in the worktree before/after committing to preserve them.
