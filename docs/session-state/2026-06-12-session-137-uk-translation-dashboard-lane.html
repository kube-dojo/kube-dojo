The lane — how agy works for translation (the hard-won knowledge)

Available gemini paths: CLI = user-retired; REST API key = deliberately unset in .envrc (free-OAuth billing); agy = the sanctioned lane. agy has two quirks, both handled:

  • Sandbox writes: for a relative output path agy ignores cwd and writes to ~/.gemini/antigravity-cli/scratch/<repo>/ (a workspace mirror). --dangerously-skip-permissions removes the prompt, NOT the mirror; --add-dir <dir> grants read. Fix: give agy an absolute output path inside an --add-dir dir → it writes in place. (User spotted this.)
  • ~3,000-word output cap: a single agy call silently abridges larger content (8100w → 3004w, even with a hardened "≥7500 words" brief) and falsely claims completeness. Fix: chunk — uk_sync.py already splits sections into ≤2.2k-word batches under the cap.

Implementation (PR #1915): dispatch_agy_translate(prompt, *, timeout) in scripts/dispatch.py wraps agy via AgyAdapter (temp-dir as --add-dir root, abs out-path, reads the file since agy returns a summary on stdout, returns (ok, text) to match the old gemini contract). The 3 dispatch_gemini_with_retry call-sites in scripts/uk_sync.py now call it; chunking / truncation-guards / frontmatter / assembly unchanged. Validated: translate modern-devops/1.5-platform-engineering (7586w EN) → 7557 UK words (ratio 1.00), 27/27 sections, 17 sections → 6 batches.

Quality — agy needs a context-aware calque pass

agy Ukrainian is good but produces occasional calques (e.g. «по мірі того як» → «у міру того як»), caught + fixed via the mcp__sources__* RAG. Nuance: «залежність» as a noun (software dependency / vendor lock-in) is legitimate — a naive «в залежності»→«залежно» fixer would corrupt it. The calque-fixer must be context-aware. → Next tooling step.
