Investigation summary — why we didn't copy learn-ukrainian wholesale

learn-ukrainian's auto-orient is not a hook trick. The mechanism is:

  • .claude/agents/curriculum-orchestrator.md — agent definition with initialPrompt: frontmatter block containing the cold-start sequence.
  • .claude/settings.json:772 — top-level "agent": "curriculum-orchestrator" sets it as the session default.
  • SessionStart hook does env validation + handoff pointer only — does not load the skill/agent.

So learn-ukrainian uses the AGENT pattern (Claude Code's native initialPrompt feature). KubeDojo uses the SKILL pattern with sub-skills (cold-start, dispatch-router, cross-family-reviewer, etc.). Converting SKILL → AGENT would tax every interactive session with ~200 lines of orchestrator context and collapse the sub-skill structure.

Chose the lighter fix: SessionStart hook prepends a one-line FIRST ACTION (per CLAUDE.md): if you have not yet invoked the curriculum-orchestrator skill this session, do it now via the Skill tool BEFORE responding to the user. to additionalContext. Reinforces, not replaces, the CLAUDE.md rule. Headless sessions (CLAUDE_NON_INTERACTIVE / KUBEDOJO_PIPELINE / GEMINI_SESSION) early-exit unchanged at line 6.
