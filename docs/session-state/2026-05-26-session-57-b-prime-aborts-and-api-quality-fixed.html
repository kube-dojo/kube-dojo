Lessons

  1. Sample-first ordering is load-bearing. The B′ deliberation outcome turned out to be wrong, but the framework caught it before stamping. The protocol's "sample, then schema" is the property to carry forward — applies to any future "skip the gate for proven-stable items" pitch.
  2. Rubric heuristic is structural-only. Lines + has-quiz + has-exercise + has-citations cannot detect title-content mismatch, mislabeled bash blocks, fake image refs, hallucinated tech, broken multi-step labs. A module can have perfect 5.0/5.0 rubric and 4 Class A defects.
  3. "No GitHub issues filed" is a weak proxy for "validated by real users." Most learners hit a broken example, get frustrated, and switch sites — they don't file issues. Zero-issues ≠ correctness.
  4. BackgroundSnapshot caches survive restart. Edit scripts/local_api.py, restart api, still see stale data. Use stop → sleep → start sequence; verify generated_at is AFTER the edit.
  5. gh issue search matches body too. Meta-epics (#1504-ish) match every module slug in starter tracks. Filter to title-only + ignore-list when using slug-in-search-results as an eligibility signal.
