DECISION NEEDED before mass-reframing the participles — how aggressively to apply the active-participle rule?
  • Context: active present participles (-ючий/-учий) are non-normative in standard UA, but modern usage is split — some are heavily lexicalized (існуючий, працюючий, домінуючий, вражаючий) and read fine; others are genuinely awkward (оточуючий редактор, fixed in 0.3). s140's full read of 0.2 stamped it "clean" while 0.2 contains 7 participles — i.e. s140 either deemed them acceptable or missed them.
  • Option A (recommended): fix all as calques — consistent with s140/s141 precedent (which fixed оточуючий/існуючий/працюючий/зростаючий/розчаровуючий). Clean drop-in swaps are scriptable safely (існуючий→наявний, конкуруючий→конкурентний); clause-reworks (оточуючий→що оточує/навколишній) need per-sentence edits. ~85 edits, ~1 focused session.
  • Option B: fix only the genuinely-awkward ones, leave lexicalized forms — honours "don't over-edit good prose", far fewer edits, but subjective per-instance and inconsistent with the 0.3/0.5 fixes already shipped.
  • The 8 "the following" (наступні команди/рядки → такі/наведені нижче) are clear regardless — do them in either option.
