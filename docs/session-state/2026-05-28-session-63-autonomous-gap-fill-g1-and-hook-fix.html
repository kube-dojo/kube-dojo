Bash hook noise — root cause and fix

Harness was surfacing "PreToolUse:Bash hook error — Failed with non-blocking status code: No stderr output" on every plain Bash call. Traced to .claude/hooks/inject-codex-danger-mode.sh:19:

TASK_CLASS=$(echo "$COMMAND" | grep -oE 'dispatch_smart\.py[[:space:]]+[a-z]+' | awk '{print $NF}')

When grep finds no match (every non-dispatch_smart Bash call), the pipeline exits 1 via pipefail. set -euo pipefail then killed the hook silently. Fixed with || true appended (PR #1629, merged).
