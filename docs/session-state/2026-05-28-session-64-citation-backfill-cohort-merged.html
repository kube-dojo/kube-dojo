Operational findings worth a memory or follow-up

1. citation_backfill writes to the PRIMARY repo dir, not the worktree

scripts/citation_backfill.py:38 sets REPO_ROOT = Path(__file__).resolve().parents[1]. When you run cd .worktrees/X && python primary/scripts/citation_backfill.py inject ..., the script's __file__ is still in primary, so it resolves REPO_ROOT to primary and writes to primary's working tree. The cd doesn't matter. To make inject land in a worktree, run the worktree's own script copy: cd .worktrees/X && /primary/.venv/bin/python ./scripts/citation_backfill.py inject ... (the worktree's scripts/ is git-copied; .venv is shared via the script's _primary_checkout_root resolver). I unwound this manually for #1631 + #1632 (copy modified file + seed to worktree, reset primary, commit in worktree). Worth a memory if more inject work coming.

2. Learner-check hook is strict on heading shape

Hook regex at .claude/hooks/_lib_pr_check.py:82: line.lower().lstrip("#").strip().startswith("learner check"). lstrip("#") only strips leading #s; ## ## Learner check becomes ## Learner check after lstrip, then .strip() gives ## Learner check which doesn't startswith "learner check". So my ## ## Learner check heading in 3 PR bodies failed the check. Fix: use literal ## Learner check (single H2). Also: blockquote must be VERBATIM from a touched module — if codex's inject wrapped a phrase in a markdown link, the quote with embedded link syntax is what the module now contains; the bare prose version no longer matches.

3. The seed `cannot_be_salvaged` disposition leaves uncited claims in prose

When the research step marks a claim cannot_be_salvaged (no source found), inject leaves it untouched. R1 then flags it as a defect ("X stat is uncited"). On 3-of-3 PRs this morning, the R1 reviewer caught this category. Filed as #1634 with 3 proposed approaches: (a) re-enable seed soften_to_illustration rewrites in inject (currently rewrites_disabled_pending_redesign), (b) per-module follow-up PRs, (c) accept-and-document. Worth a Decision Card next session.
