The brain-rot canary experiment (the session's headline)

User wanted to push context toward 700K and verify the "Opus 4.8 has no brain rot" claim empirically rather than trust it. Ported learn-ukrainian's deterministic canary to scripts/quality/context_canary.py. Protocol: mint K immutable anchors (merged SHAs, PR/issue #s, locked decisions) with ground truth captured deterministically; at each checkpoint, answer the same anchors from memory (no scrolling back) into a JSON; the SCRIPT diffs vs frozen truth (difflib ≥0.75 per anchor, ≥0.85 pass-ratio). The model cannot grade itself into a pass.

Policy moves locked this session

1. Tiered handoff thresholds (raised)

Retuned ~/.claude/context-check.sh (the live Stop-hook) and ~/.claude/statusline.sh from 300/400/450K to 500/600/700K (cap 750K). 500K = early signal; 600K = "run a context-integrity self-check before continuing" (the canary is that check); 700K = hard handoff. Rationale: handing off late fails silently (rot isn't self-reported), but the canary makes "push higher" safe to measure. Project .claude/statusline/statusline.sh (percentage-based, red at 80%≈600K) left as shared default.

2. Context canary ported + formalized

scripts/quality/context_canary.py (mint/score/log) committed. The standing policy: monitor rot DETERMINISTICALLY across long sessions; answer from memory; the script grades; drift below pass-ratio → hand off NOW regardless of token count. Mint ONLY immutable anchors (a fact that changes mid-session reads as drift, not rot).
