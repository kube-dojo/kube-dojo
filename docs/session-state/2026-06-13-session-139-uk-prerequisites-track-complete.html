The proven lane — fix-section --strict-commit

In .worktrees/uk-bulk on a fresh branch off main: python scripts/uk_sync.py fix-section <section> --strict-commit (run from the worktree so REPO_ROOT resolves there). Detects + re-translates only stale modules, skips synced, preserves frontmatter, re-stamps en_commit — no manual rm. Simpler than s138's uk_bulk.sh driver.

--strict-commit is MANDATORY: the s100–135-expanded stubs carry an OLD en_commit, and non-strict detect_sync treats a commit mismatch as a WARNING, not stale → a plain fix/fix-section prints "✓ Already synced" and SKIPS the stub (the board flags it stale by word-ratio; the two detectors disagree). agy is SEQUENTIAL-ONLY (one batch at a time). Run batches via the tracked run_in_background (NOT nohup & — that gives no completion notification).

CI gate fix (#1922, in PR #1921)

The Ukrainian Russicism check (scripts/checks/ukrainian.py) false-failed two correct patterns that recur constantly in good Ukrainian, so it was about to block every future batch:

  • являється inside з'являється — the word-boundary class had ASCII ' (U+0027) but not the typographic ' (U+2019) Ukrainian uses → fixed by adding U+2019 + U+02BC to the boundary class (apostrophe-joined morphemes are one token).
  • нормально — VESUM-confirmed standard Ukrainian; moved to an advisory CONTEXTUAL_RUSSICISMS set (severity INFO, non-failing).
  • Regression tests added; dead dataclass import removed (ruff clean); pytest 7/7.

  • Recurring gate false-positives on legitimate words. рахувати (count) and в цілому keep tripping the gate. рахувати is correct for counting (only a Russism for "consider") — rephrase legit count uses to підраховувати. в цілому → загалом is a genuine calque fix.
