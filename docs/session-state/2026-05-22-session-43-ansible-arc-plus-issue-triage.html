  • PR #1437 (Module 7.16): claimed metav1.Condition has severity field. Actual k8s.io/apimachinery type has observedGeneration. Also claimed controller-runtime workers can process the same CR key concurrently — false, queue is per-key exclusive. Sources list omitted the API Conventions URL the prose cited as authoritative.
  • PR #1438 (Module 7.14): ansible.eda.k8s source plugin does not exist in ansible/event-driven-ansible v2.12.0 (verified plugin list: alertmanager, aws_cloudtrail, aws_sqs_queue, azure_service_bus, file, file_watch, generic, journald, kafka, pg_listener, range, tick, url_check, webhook). Plus kubernetes.core.k8s inventory plugin was removed in v6.0.0. Plus kubectl apply -k github.com/ansible/awx-operator/config/default?ref=2.19.1 silently pulls :latest image (kustomization.yaml has newTag: latest) — exactly the pinning anti-pattern the module's own Common Mistakes warns against.
  • PR #1439 (Module 7.13): dependentWatches and numWorkers are not documented watches.yaml fields. SDK reference table only has: blacklist, watchDependentResources (boolean), selector, manageStatus, reconcilePeriod, watchClusterScopedResources, finalizer, snakeCaseParameters, maxRunnerArtifacts, watchAnnotationsChanges. Worker concurrency is controlled via ANSIBLE_WORKERS env or --max-concurrent-reconciles flag, not per-entry in watches.yaml.
  • PR #1440 (Module 7.17): kuttl 02-delete-cr step had assert.yaml with collectors only — collectors gather diagnostic info on failure, do NOT assert absence. The actual absence-check mechanism is errors.yaml. Plus the envtest sidecar section was factually wrong (setup-envtest use downloads binaries but doesn't start an API server; doesn't generate a kubeconfig). Removed envtest section, replaced with expanded Molecule driver comparison.
  • PR #1434 (kafka): self.healing.broker.failure.threshold.ms doesn't exist in Cruise Control. Actual key from SelfHealingNotifier.java:60 is broker.failure.self.healing.threshold.ms. Wrong key → CC silently ignores it, falls back to default ~30min threshold.
  • PR #1435 (Module 7.15): "When Ansible Operator Wins" examples cited NVIDIA Network Operator + MinIO Operator — both are Go operators in production. Replaced with AWX Operator (verified Ansible SDK at ansible/awx-operator) + a hypothetical vendor-playbook archetype framed explicitly as illustrative.
