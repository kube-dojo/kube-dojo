3. deepseek's recurring failure modes (predictable → catch them cheaply)

Across 5 modules deepseek's real defects were consistent and mechanical — worth baking into the fidelity brief and/or a pre-normalizer to cut the fix load on the remaining ~160 ai/ai-ml modules:

  • Active-participle russicisms: існуючий→наявний, конфліктуючий→конфліктний.
  • "is located" calque: знаходиться/знаходяться→перебуває/перебувають (but знаходить=finds is correct — context-check).
  • "against" = targeting mistranslated as проти (opposed) → до/над/з/у (but аргумент проти, бар'єри проти = correct "against").
  • Grammar: обоє (people) used for tools/things → обидва.
  • False friends: redact→редагувати (should be маскувати); reclaims→повертає (should be вивільняє); assert(test)→стверджує (should be перевіряє).
  • Idiom literal-calques: mystery-meat, short-circuit(programming), OpenAI "writing", "cookbook" → all rendered literally/wrong. These are the true gate-invisible P1s only a vs-EN read catches.
  • Transliterated slang: флаки, іш'ю → translate properly.
