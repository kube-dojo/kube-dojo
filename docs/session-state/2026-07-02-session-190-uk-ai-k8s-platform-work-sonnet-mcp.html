Review lessons (worth remembering)

  • Verify reviewer flags — both ways. deepseek's викатка flag was real (MCP-confirmed) but its продакшн-is-better nit was wrong (contradicts glossary + #2110). agy's grammar flag відповідєю was a false positive — the actual file text is the correct відповіддю (caught by grepping the file). Never act on a sandboxed reviewer's claim without checking the source.
  • Class-A "fix ALL siblings." Giving the first fix-pass only codex's 2 listed redact lines left a 3rd (table cell) that agy's re-review caught. The final fix-pass, told to grep for all siblings, found 6 redact instances in 1.2, not 3. Always instruct fix-passes to fix every occurrence.
  • Converge after two rounds. R1→fix→R2 caught real defects; a hypothetical R3 would only surface stylistic nits indefinitely. Ship on confirmed P1/P2 + clean deterministic gates, not endless polish.
  • Apostrophe-declension is corpus-valid but was a section outlier. The decision to normalize 1.2 was about intra-section consistency (4/5 files + brief rule #5), not correctness. A corpus-wide normalization is a separate 157-file call — not made unilaterally.
