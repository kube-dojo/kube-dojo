Lessons / catches worth carrying forward

  • Code-heavy certs = the T0 verifier is blind to correctness. Every cert this session had real, learner-/lab-breaking P1s the verifier passed (removed/fabricated CRDs, wrong Go propagation order, schema-invalid connector config, duplicate YAML key, JSON6902 missing-parent, wrong metric labels). Brief reviews explicitly toward "compile-conceptually / build-against-the-pinned-version" and route ≥1 review to opus 4.8 — it caught all of them.
  • Leaked production/authoring meta-text is shipping into learner content. CBA 1.3 had a literal leaked prompt ("…feature X was introduced in v1.1…v1.7… Kubernetes versions must strictly be v1.35…"); OTCA 1.1 had "the audit failure called out a common curriculum problem…". The anti_leak gate misses these (not emoji/token). A sibling grep found the same pattern in cnpe/1.4 (wave 2) + 2 out-of-scope modules (see Follow-up 2).
  • Ground-checking caught/confirmed reviewer hedges both ways. Web-confirmed opus's KCA metric-label fix (rule_result), the Backstage v1.49.0 date (Mar 18 2026), the countconnector schema, the BGPv1-removed-in-1.19 fact. Where I couldn't verify (KCA kyverno apply exit-code-2), I had the fixer soften rather than assert a possibly-wrong value.
  • CNCF maturity web-verified (memory feedback_web_verify_cncf_maturity held). Confirmed: Cilium Graduated 2023-10, Argo Graduated 2022-12, Backstage Incubating, OTel Graduated 2026-05-11, Kyverno Graduated 2026-03-16 (STATUS/briefing wrongly said "Incubating" — now corrected).
