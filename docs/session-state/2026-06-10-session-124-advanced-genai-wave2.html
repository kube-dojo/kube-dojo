Reviewer findings overturned by orchestrator ground-check

Two reviewer P1/nit recommendations were wrong and caught by ground-checking before applying:

  • 1.9 PiSSA A/B "swap" (cursor P1) — FALSE POSITIVE. cursor read the PiSSA paper's A/B labels (A=U·S½, B=S½·Vᵀ), but the module uses PEFT's B@A convention where the forward is (W_res + B×A)·x. The fix brief explicitly withdrew it; the fixer left the math alone and added a clarifying note.

These modules need Outcomes-first (deepseek's 1.9 independently reordered the same way). Reverted; kept opus's two valid nits (Bard figure precision, [A-Z|a-z]→[A-Za-z] regex).
