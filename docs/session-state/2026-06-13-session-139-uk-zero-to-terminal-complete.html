Lane improvement — fix-section --strict-commit (simpler than s138's uk_bulk.sh driver)

s138 used logs/uk_bulk.sh (rm the stub → uk_sync.py translate → calque-autofix). This session used a cleaner path: python scripts/uk_sync.py fix-section prerequisites/zero-to-terminal --strict-commit (run from the worktree so REPO_ROOT resolves there). It detects + re-translates only the stale modules and skips synced ones — no manual rm, frontmatter preserved, en_commit re-stamped automatically.

The --strict-commit gotcha (critical for every future batch): the /uk board measures currency by word-ratio, but uk_sync.py detect_sync measures it by en_commit match. The s100–135-expanded stubs each carry an old en_commit, and non-strict detect_sync treats a commit mismatch as a WARNING, not stale — so a plain fix/fix-section prints ✓ Already synced and skips the stub. Pass --strict-commit to promote the mismatch to stale. (This is why s138's 0.1–0.4 run worked — same flag.)

The CI gate fix (#1922)

The Ukrainian Russicism check CI job (scripts/checks/ukrainian.py via scripts/quality/check_uk_changed.py) failed PR #1921 on two false positives:

  • являється inside з'являється — the word-boundary class (?<![а-яґєіїА-ЯҐЄІЇ']) included the ASCII apostrophe ' (U+0027) but not the typographic ' (U+2019) Ukrainian routinely uses, so являється after a typographic apostrophe (з'являється = "appears", correct) matched the standalone-calque rule. Fix: add U+2019 + U+02BC to the boundary class — apostrophe-joined morphemes are now one token. (ASCII-apostrophe and виявляється were already correctly skipped; only the U+2019 variant leaked.)
  • нормально — VESUM-confirmed standard Ukrainian adverb (check_russian_shadow → false, conf 0.0); idiomatic in «це нормально» / «працювати нормально». Moved to an advisory CONTEXTUAL_RUSSICISMS set (severity INFO, passed=True) — surfaced for human review but never a hard CI failure.
  • Regression tests added (U+2019 з'являється + standard-context нормально pass; a genuine standalone являється still fails); dead dataclass import removed (ruff clean).
