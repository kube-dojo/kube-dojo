2 · #1823 mermaid — real live-site defect, fixed + gated (PR #2071, merged 7c329ba90)

Triage found #1823 was not closeable cruft: the acute case was fixed in #1824, but the lint tool scripts/ci/check_mermaid_labels.py was never wired to CI and the corpus was never swept. Running it: 40 flagged lines / 43 labels across 11 files still had unquoted ( inside flowchart [..]/{..} node labels — which abort the whole diagram and render as raw code in the browser. No existing gate catches this (mermaid renders client-side).

  • Added a deterministic --fix mode to the lint, driven by the same SQUARE/RHOMBUS regexes as the detector → a fixed line is, by construction, no longer a violation. Selftest extended to assert --fix resolves every bad case and leaves every good case byte-for-byte unchanged.
  • --fix applied: 43 labels quoted across 11 files (cloud, linux, kcna, on-premises, ai-infrastructure). HTML (<br>/<i>/<b>/•) preserved inside quotes (securityLevel: loose → htmlLabels render); round nodes (...) and bare nodes left untouched.
  • Wired the stdlib-only check into the always-on link-check job (no paths: filter → required-safe). Post-fix re-scan on main: 0 violations. ruff + zizmor clean; astro build green.

Lesson: a deterministic detector can also be a deterministic fixer — share the regexes, and the re-scan-to-0 is the verification. Cheaper and safer than 43 manual edits.

3 · #1876 AI-history book — Phase 1 sample review

73 chapters / ~365K words, live in the sidebar, never cross-family reviewed. Reviewed the issue's recommended 5-chapter sample (ch-14 Perceptron, ch-26 Bayesian Networks, ch-43 ImageNet, ch-50 Transformers, ch-71 Chip War) on a factual-accuracy / no-fabrication lens.

Two independent modalities + two deterministic corpus scans

  • Orchestrator (opus) web-verified ~20 high-risk anchors across the sample.
  • codex (cross-family) independently web-verified against PubMed, APS, ImageNet official pages, Russakovsky 2015, BIS/Federal Register, ASML, TSMC, NIST CHIPS, SEC, etc.
  • arXiv ID check across all 73 chapters: 13 IDs, 0 mismatch, 0 unverifiable.
  • Lifespan/date anomaly scan across all 73: 0 anomalies (every flagged token was a correctly-used concept-era range / citation page range / projection interval — e.g. ch-15 gradient-descent 1847–1970 with Cauchy's exact lifespan 1789–1857).

Result: ZERO fabrications

Every verified anchor — including the categories fabrication usually botches (obscure journal vol/issue, exact death years, specific officials, precise percentages, dataset sizes) — was correct. Highlights: H.D. Block Reviews of Modern Physics 34(1), 1962 (exact); Charniak 1946–2023 (exact death year); AlexNet 15.3% vs 26.2%; ILSVRC2012 1,431,167 images; Pearl 1936 / Hinton 1947 / Sutskever 1986. The chapter even correctly distinguishes 15.3% (winning ensemble) from 16.4% (single-model retrospective figure) — the opposite of a fabrication pattern.

What the review surfaced (precision, not fabrication)

  • ch-43 — one real factual slip (fixed, PR #2072): used 150,000 (the AlexNet paper's ILSVRC-2010 figure) as the 2012 test-set size and derived miss-counts (~39,000 / ~23,000) from it. Official ILSVRC2012 = 100,000 → ~26,000 / ~15,000. Error rates were all correct.
  • ch-71 — reviewer false-positive caught: codex flagged "Jeffrey Kessler" as misspelled ("Jeffery"). Ground-check confirms "Jeffrey Kessler" is correct (Senate-confirmed Under Secretary/BIS, Mar 2025). No change. Reviewers fabricate too → every flag ground-checked.
  • Minor framing/currency (Phase 2, non-blocking): ch-26 "direct ancestor of modern PGMs" overstates; ch-50 "NeurIPS 2017" is the retroactive name (venue was "NIPS 2017"); ch-50 narrow "Bahdanau introduced attention"; ch-14 Tobermory attribution; ch-71 add the 2025 MOFCOM No. 72 update.

Decision

The book is carefully sourced and NOT fabrication-heavy. Per the #1876 gate: no full blind 73-chapter epic — targeted spot-checks + the specific corrections only. Keep it OFF the module quality board (book-format; verify_module.py N/A). The cheap deterministic layers (arXiv + lifespan/date) are already green corpus-wide and worth keeping as the standing guard. Full decision recorded on #1876.

5 · Gotchas / lessons

  • Triage that finds a real bug should fix it, not close-and-forget — #1823 had 40 broken diagrams; closing it unfixed would have lost a live-site defect. Fixing it produced the clean 2-issue board and the quality win.
  • A GitHub closing keyword in the PR body auto-closes the issue — "Closes … (#1823)" in PR #2071's body closed #1823 on merge before my gh issue close -c could add the evidence comment (posted separately).
