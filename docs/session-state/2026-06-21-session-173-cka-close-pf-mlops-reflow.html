The key finding — pf-mlops is a REFLOW wave, not a rewrite wave

s172b framed the remaining 9 as "heavy multi-session remediation". Ground-truthing corrected it: all 9 fail the density cluster because the teaching prose is written one sentence per paragraph (every sentence on its own line → median words-per-paragraph ~7–9 vs the 28 floor). Verified against extract_body_paragraphs (which excludes code/tables/lists), so it is genuine prose fragmentation, not a metric artifact and not thin content. The fix is a faithful reflow (join sentences into 4–6 sentence paragraphs) — far cheaper than a rewrite. One author wrote the whole sub-track this way.
