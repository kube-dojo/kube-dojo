Світ розробки та розгортання програмного забезпечення кардинально змінився. Минули ті часи, коли сервери налаштовувалися вручну, монолітні застосунки працювали на окремих серверах, а розгортання були рідкісними та вкрай ризикованими. На їхнє місце прийшла парадигма cloud native — сучасний підхід до створення та запуску застосунків, який повною мірою використовує переваги моделі хмарних обчислень.

Цей розділ є базовою передумовою для проходження KubeDojo. Незалежно від того, чи ви переходите від традиційного системного адміністрування, чи ви розробник, який прагне зрозуміти платформу, на якій працює ваш код, ці модулі розкриють та пояснять ключові концепції. Ви побудуєте міцну ментальну модель інфраструктури та архітектурних патернів, які є рушійною силою сучасних технологічних компаній.

Наша подорож починається з найнижчого рівня абстракції — з вивчення контейнерів та того, як вони ізолюють процеси. Далі ми розглянемо Docker — інструмент, який популяризував контейнеризацію, після чого піднімемося на рівень вище, щоб зрозуміти, чому системи оркестрації, такі як Kubernetes, є необхідними при масштабуванні. Нарешті, ми складемо карту ширшої екосистеми Cloud Native Computing Foundation (CNCF) та дослідимо архітектурний перехід від монолітів до мікросервісів, який і робить усю цю екосистему такою цінною.
